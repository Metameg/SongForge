# Home dev server: design

Status: design approved in conversation 2026-11-23. Items marked **(call)** are Claude's
and not yet confirmed.

## Intent
Host SongForge on a home Ubuntu Server LTS box as a free stand-in for the Railway staging
setup: tracks `development`, uses the MusicGPT simulator, is reachable through Cloudflare
with no router ports opened, and is where the k6 tests run.

## Goals
- Public HTTPS at one subdomain (`dev.<domain>`) of the Cloudflare-hosted production domain.
- SSE radio, audio seeking and song downloads work through the tunnel.
- Update = `git pull` + one script. Survives a reboot.
- k6 runs on the server against localhost, with Prometheus/Grafana on.
- One command wipes simulated songs.

## Non-goals
Real MusicGPT, R2, auto-deploy, a second load-test stack, per-IP quotas (limits are off).

## Anti-goals
Changing how the laptop stack behaves; exposing a datastore to the LAN or internet;
committing a secret (the repo is public).

## Constraints
- Simulator on; `ENFORCE_RATE_LIMITS=false`.
- Named tunnel only: Quick Tunnels do not support SSE and cap at 200 in-flight requests.
- One hostname, one label deep (free certificate). Cloudflare Access covers all of it.
- Cloudflare's read timeout is 125s; the SSE heartbeat is 30s.
- Free-plan terms on media are a low risk for a private dev site; production audio belongs
  on R2.

## Approaches
- **A, chosen:** Compose overlay plus a `cloudflared` container, MinIO for audio.
- B: same overlay with Tailscale Funnel. No domain needed, but beta and bandwidth-limited.
- C: separate full Compose file. Drifts from `docker-compose.yml`.

R2 was considered for audio and dropped by the user in favour of MinIO.

## Design
- `/songforge-audio/*` on the hostname goes to `minio:9000`; everything else to
  `frontend:3000`.
- Postgres, Redis, MinIO and simulator publish no ports. `lb`, `frontend`, Prometheus and
  Grafana bind `127.0.0.1`.
- Secrets live in `deploy/server/.env` on the server, generated by a script **(call)**.
- Every long-running service gets `restart: unless-stopped`.
- **Wipe (call):** deletes the Postgres, Redis and MinIO volumes together, then restarts the
  stack, which reseeds the library. Deleting only MinIO objects would leave database rows
  pointing at missing audio, which the radio would still schedule.
- **Full-size simulator MP3 stays** (user chose a wipe command). At the 50-job cap and 5s
  delay that is up to about 24 GB per 10 minutes, so the load-test script refuses to start
  with under 30 GB free unless `FORCE=1` **(call)**.

## Left to the builder
Script internals, test layout, wording of the operator guide.
